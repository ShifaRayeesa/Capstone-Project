## Reproduce

1. **Clone the repository** and make sure you are working on the `main` branch:
   git clone https://github.com/ShifaRayeesa/Capstone-Project.git
   cd Capstone-Project
   git checkout main


2. **Create an isolated virtual environment** named `.venv`:
   python -m venv .venv

3. **Activate the virtual environment**:
     source .venv/bin/activate

4. **Install the dependencies**:
   pip install -r requirements.txt
